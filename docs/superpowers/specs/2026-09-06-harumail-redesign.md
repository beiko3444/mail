# 하루메일 UI/UX 전면 개편

한국 이용자를 위한 무료 임시메일이라는 확정 방향을 유지한다. 사용자는 기존 UI/UX의 전면 개편을 요청했다. 디자인은 흰색과 선명한 파란색, 여유 있는 간격, 일관된 선형 아이콘을 사용한 메일 앱으로 정한다. 과도한 소개 화면이나 기능을 암시하는 가짜 지표를 넣지 않는다.

## 핵심 경험

- 데스크톱: 왼쪽의 간결한 서비스 메뉴, 오른쪽의 주소 카드와 받은편지함. 주소 발급과 복사가 첫 화면에 보인다.
- 모바일: 짧은 상단 메뉴와 한 열 레이아웃. 메일 열기는 목록을 대체하고 목록으로 돌아가기 버튼과 포커스 복귀를 제공한다.
- 주소 생성 전에는 만들기를 주 행동으로, 생성 후에는 복사를 주 행동으로 표시한다. 새 주소와 닫기는 확인 대화상자에서 결과를 구체적으로 설명한다.
- 메일함이 비어 있을 때에는 다음 행동과 자동 확인 상태를 안내한다. 메일이 없는데 빈 본문 영역을 별도로 계속 표시하지 않는다.
- 메일 상세·연결 오류에는 다시 시도할 수 있는 행동을 제공한다. 복사 실패 시 주소 대신 실제 복사 대상(인증번호 포함)을 선택할 수 있는 대화상자를 표시한다.
- 주소 복사는 버튼에서 확인할 수 있게 피드백을 주고, 백그라운드 수신 상태가 그 피드백을 지우지 않도록 한다.
- 폴링의 목록 갱신은 키보드 포커스를 잃게 하지 않는다. 요청 경합 방지, 다른 메일함 보호, 텍스트 본문만 표시하는 보안 경계를 유지한다.
- FAQ·가이드·소개·정책에도 동일한 메뉴·타이포그래피·색상과 읽기 폭을 적용한다.

## 범위와 검증

기존 Vercel/Node 구조, 인증·수신 API, 24시간 정책, 실제 도메인과 AdSense 설정은 유지한다. UI를 위해 추가 계정이나 유료 서비스를 만들지 않는다. 배포는 기존 PR의 미리보기를 갱신한다. 공개 연락처 등 미확정 운영 정보는 만들지 않으며 상용화 완료라고 표현하지 않는다.

기존 자동 테스트와 추가 동작 회귀 테스트로 복사 실패, 재시도, 모바일 상세 복귀, 자동 갱신 시 포커스 유지 및 요청 경합을 검증한다. 정적 출력의 경로·메타데이터·광고 경계와 반응형 규칙을 확인한다. 브라우저 테스트는 별도로 요청된 경우 수행한다.
