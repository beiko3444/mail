# 하루메일 모션 중심 UI 개선

## 목표

임시메일 발급이 첫 화면의 중심 경험으로 느껴지도록 시각적 위계를 강화하고, 새 주소 발급이 완료되는 순간에 짧고 절제된 피드백을 제공한다. 메일 발급·복사·수신 API와 24시간 정책은 바꾸지 않는다.

## 화면 구성

- 기존 좌측 메뉴와 한 화면 메일함 구조를 유지한다.
- 메인 배경에는 낮은 대비의 푸른 그라디언트와 격자 질감을 사용한다. 메일함 카드는 반투명한 흰색 표면, 넓은 여백, 선명한 파란색 포인트로 구분한다.
- 주소 영역은 발급 전에는 시작 행동을 강조하고, 발급 후에는 주소·복사 행동을 가장 쉽게 읽히도록 한다.
- 받은편지함과 안내 영역의 정보 구조·링크·모바일 한 열 레이아웃은 유지한다.

## 주소 발급 모션

발급 요청이 시작되면 메일함 카드에 처리 상태를 드러낸다. API 응답으로 새 주소가 설정되면 주소 영역에 한 번의 짧은 진입 모션을 적용한다. 카드 외곽의 푸른 광택, 주소 텍스트의 위로 올라오는 전환, 복사 버튼의 짧은 강조 순서로 완료를 전달한다. 모션은 장식용일 뿐 발급 완료 상태를 대신하지 않으며, 실패 시에는 실행하지 않는다.

`prefers-reduced-motion: reduce`에서는 변형·반짝임·순차 전환을 적용하지 않고 즉시 상태를 바꾼다. 새 주소 버튼의 중복 요청 방지와 기존 확인 대화상자는 그대로 유지한다.

## 접근성 및 검증

- 상태 문구는 기존 `role=status` 라이브 영역으로 유지한다.
- 모션은 키보드 포커스를 이동하거나 주소 입력 필드의 읽기 상태를 바꾸지 않는다.
- CSS 클래스는 발급 성공 시에만 추가하고, 애니메이션 종료 뒤 제거해 이후 새 발급에서도 재실행되게 한다.
- 단위 테스트는 성공적인 새 주소 발급 시 모션 클래스가 추가되고, 모션 종료 뒤 제거되는지 검증한다. 기존 메일함·수신·SEO 테스트 전체도 통과해야 한다.
