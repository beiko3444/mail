# 하루메일 무료 서비스와 광고 신청 준비

사용자가 서비스명을 **하루메일**로 확정했으며, 한국 이용자를 대상으로 먼저 제공한다. 기본 언어는 한국어다.

사용자가 선택한 무료 모델을 기존 GitHub/Vercel 사이트에 적용한다. 유료 기능이나 결제를 추가하지 않는다. Temp Mail의 주소·복사·새로고침·수신함 흐름만 참고하고 브랜드, 디자인, 설명, 가이드는 새로 작성한다.

## 사용자 경험
- `/`에서 가입 없이 무작위 주소를 발급한다. 복사, 받은편지함 갱신, 새 주소, 메일함 닫기를 제공한다.
- 서버가 서명한 HttpOnly 세션 쿠키로 메일함을 보호한다. 임의 주소나 메시지 ID만으로 메일에 접근할 수 없다. 이전 전역 주소 목록 API는 폐쇄한다.
- 메일함은 발급 후 24시간 이용할 수 있다. 닫기/만료는 서비스 접근 종료이며 Resend 원본 즉시 삭제를 의미하지 않는다. 이를 화면과 개인정보처리방침에 명시한다.
- 메일 본문은 텍스트로만 표시하여 원격 이미지·추적 픽셀·스크립트를 실행하지 않는다. 첨부파일은 첫 무료 버전에서 다운로드하지 않는다.

## 공개 콘텐츠와 광고 경계
- 이용 가이드 5편, FAQ, 소개, 문의, 개인정보처리방침, 약관을 정적 HTML로 제공한다. 메뉴, 모바일 레이아웃, 키보드 접근, 오류 페이지, 제목/설명, canonical, robots, sitemap을 적용한다.
- 수신함, API, 법적 고지, 문의, 오류 페이지에는 광고 스크립트/광고 단위를 삽입하지 않는다. 가이드 본문만 향후 수동 광고 대상으로 허용한다. 자동 광고는 사용하지 않는다.
- 실제 게시자 ID 없이 가짜 ads.txt 항목이나 소유권 태그를 만들지 않는다. 게시자 ID가 있으면 정적 메타태그와 ads.txt를 생성한다. 광고 코드는 승인·동의 설정이 완료되기 전 비활성 상태로 둔다.
- Google은 사이트 전체를 심사하므로 콘텐츠 분리가 승인을 보장하지 않는다. 공개 문의 주소, 실제 계정 자격/결제정보, 사이트 소유권 확인, CMP 설정, 심사 제출은 계정별 확인이 필요하다.

## 구현과 검증
Node 기본 라이브러리만 사용한다. Vercel과 로컬 서버는 같은 API 핸들러를 공유한다. 정적 빌드는 공개 자산만 dist에 포함한다. 인증 누락·위조·만료·다른 메일함 접근, 수신 API 페이지네이션, 응답 캐시 방지, 광고 경계, 비밀파일 배포 제외, 링크/메타데이터를 자동 검증한다.

## 남은 외부 정보
애드센스 게시자 ID와 공개 문의 이메일은 사용자에게 요청했다. Vercel Hobby의 상업용 제한에 따라 광고 수익화 배포 전 플랜/호스팅을 확인한다. 유료 플랜 구매는 실행하지 않는다.
