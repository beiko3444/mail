# AdSense application preparation

Scope: prepare the existing public HaruMail website and the real AdSense site record. Google alone decides approval; do not submit while material known gaps remain.

1. Verify the publisher account, actual production domain, ownership and official policies.
2. Correct outdated receiver/retention descriptions. Expand existing translated guides with practical steps, examples, sources and clear editorial responsibility rather than creating thin keyword pages.
3. Publish only operator/contact details the owner explicitly supplies. Improve multilingual contact and cookie explanations.
4. Keep advertising out of inboxes, private content and error screens. Separate application readiness from post-approval ad activation/CMP requirements.
5. Run the build, meaningful privacy/metadata regressions, link and browser checks; deploy the scoped changes and check production.
6. Record remaining account, contact and consent setup honestly. Do not treat an automated preflight as Google approval.
