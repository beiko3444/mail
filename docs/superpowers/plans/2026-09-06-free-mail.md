# Free Mail Implementation Plan

**Goal:** 무료 임시메일 서비스와 애드센스 신청 준비 페이지를 기존 사이트에 적용한다.
**Architecture:** Node CommonJS API + 서명 쿠키 + 정적 콘텐츠 빌드. 브라우저는 메일함 쿠키로 인증하고 광고는 가이드 페이지에만 별도 연결한다.
**Tech Stack:** Node 내장 crypto/http/fs/test, HTML/CSS/JavaScript, 기존 Resend API/Vercel.

- [ ] `tests/mailbox.test.js`: 인증 없는 조회, 임의 주소 조회, 다른 메시지 조회, 만료, 변조, 쿠키 속성, 페이지네이션을 검증하는 실패 테스트부터 작성한다.
- [ ] `api/_lib/mailbox.js`, `api/mailbox.js`, 기존 메시지 API: 24시간 서명 세션, 세션에서 주소 추출, 입력/Origin 제한, 조회 범위와 오류 처리 구현. 전역 aliases API는 410.
- [ ] `api/_lib/resend.js`: 제한된 페이지네이션과 페이지 캐시/동시 요청 합치기. 부분 조회를 명시하고 메일 본문·첨부링크 유출 방지.
- [ ] `index.html`, `app.js`, `styles.css`: 주소 생성/복사/교체/닫기, 수신함·텍스트 상세, 응답 경합 및 만료 처리, 키보드/모바일 사용성 구현.
- [ ] `content/`, `scripts/build.js`, `site.config.json`: 원본 가이드와 공개 정책 페이지, 정적 메타데이터/메뉴/사이트맵, 게시자 ID가 있을 때만 검증 태그와 ads.txt 생성.
- [ ] `server.js`, `vercel.json`, `package.json`: 공개 출력만 제공, 동일 API 동작, 보안 헤더, 404, Node 테스트/빌드 스크립트 추가.
- [ ] `tests/site.test.js`: 공개 파일 제한, 광고 경계, 링크/정책/구조 검증. 실제 로컬 HTTP smoke test 후 변경사항 전달·배포 가능한 경로 확인.

검증 명령: `node --test tests/*.test.js`, `node scripts/build.js`, 로컬 서버의 공개 경로 HTTP200 / 알 수 없는 경로404 / 비밀파일404 / 인증 없는 메일401을 확인한다. 실제 메일 수신은 테스트 데이터와 구분해 보고한다.
